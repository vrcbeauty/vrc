# VRC BEAUTY Catalogue

## GitHub upload structure

Upload these files to the ROOT of your GitHub repository:

- index.html
- style.css
- script.js
- logo.png
- product-01.jpg through product-76.jpg

Each product image is referenced directly by filename. There is NO images folder.

## Image naming

Match each product number to its image:

product-01.jpg = Product 1
product-02.jpg = Product 2
...
product-76.jpg = Product 76

Keep the spelling, hyphens, and file extensions exactly as shown.

## Features

- Responsive product catalogue
- 76 products and prices
- Search
- Shopping-cart icon with item count
- Add to Cart does NOT open the cart automatically
- Customer opens the cart manually
- Quantity + / - controls
- Button-style trash/remove control
- 12-hour cart expiration
- WhatsApp checkout to +2348145935394
- VRC BEAUTY branding and contact details
